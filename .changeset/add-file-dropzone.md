Adiciona o componente `FileDropzone`: área de upload por arraste ou clique, com `input type=file` oculto, estado dos arquivos selecionados (nome + tamanho + remover) e emissão via `onFilesSelected`. Parametrizável por `accept`, `multiple`, `title`, `description` e `icon`. Puramente visual — o envio fica no chamador.
